Three keys made from the same seed phrase protect you from nothing. If that one seed is stolen, all three keys go with it. Each key must come from a different device or a different seed phrase.

Confirm before you start

The factory builds wallets. One per network is enough and everyone shares it, so you usually just paste an address someone already deployed. Look it up on a block explorer first and check its code is verified. If this network has no factory yet, deploy one with forge script script/Deploy.s.sol from the repo, then paste the address it prints.

Who approves this

Use this on your second device. Scan the request, read what it actually does, then approve it. This device checks the request itself, so a compromised main phone cannot lie to you about what you are signing.

Add a daily key

A daily key lives on your phone and spends on its own, up to a limit each day, until it expires. Setting one up needs your master key and your authenticator.

Emergency stop

Turns off every daily key on this wallet right away. Your master key, authenticator and backup key keep working. Use this the moment a phone goes missing or something looks wrong.

Not audited. Test with small amounts first. Your keys never leave your devices, and this page never sends them anywhere.
